## What's new in v1.2.25

- **Auto-correct fixes more words that end in a letter key.** A word whose last key is a letter only on the other layout is now corrected too: `rfhf,f[ ` becomes `карабах `, `gj[j; ` becomes `похож `. Before, such words were left as typed. Two-letter words like `vj]` (`мої`) are still fixed only together with the next wrong-layout word (`vj] lheu ` → `мої друг `), so English abbreviations like `vs.` are left alone.
- **Auto-correct is greyed out when it can't work.** If all your enabled keyboard layouts use the same alphabet (for example ABC and German), the checkbox in Settings is now disabled, and the ⓘ next to it explains why and lists your layouts. Your setting comes back as soon as you enable a layout with a different alphabet. The hotkey works as before.
- Tooltips in Settings now appear immediately.
