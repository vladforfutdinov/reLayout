## What's new in v1.2.26

- **Enter fixes a wrong-layout word again, when it starts a new line.** Type `ghbdtn` and press Enter in TextEdit, Notes or another text editor: the line becomes `привет`, and the cursor is on the new line. Sending a message or a search still uses exactly what you typed: in Telegram `ghbdtn` + Enter sends `ghbdtn`, while Shift+Enter (a new line) fixes it. Enter itself is never delayed. You can turn this off in Settings → *Also fix on Enter*.
- This works in apps that let reLayout read the text field (most native Mac apps and Telegram). In browsers and apps like VS Code or Slack, Enter behaves as before and does not fix the word.
- Undoing a fix with the hotkey right after Enter or Tab now puts back a real Enter or Tab instead of an invisible character.
