## What's new in v1.3.0 — Windows (preview)

- **First Windows builds of reLayout** — an installer (`reLayout-windows-x64-setup.exe`, `reLayout-windows-arm64-setup.exe`) and a portable `.exe` for x64 and ARM64.
- **Hotkey on a selection:** a combo or a tap of a single modifier (double tap too) retypes the selected text in the right layout and switches the layout; press it again right away to undo.
- **Auto-correct while typing** (off by default), with the Enter follow-up, short words like prepositions, and an exceptions list (terminals, editors, VMs and remote desktops preset). Password fields are skipped.
- **Settings and tray** in light and dark themes, in the same 12 languages as the Mac app; a tray notice and menu item when a newer release is out.
- **Not code-signed yet:** SmartScreen asks to confirm the first run ("More info" → "Run anyway"). Updates are not installed automatically — download the new release.
