## What's new in v1.3.10 — macOS

- Auto-correct learns from you. When it leaves a word alone and you convert it with the hotkey, it remembers that word and fixes it next time ("учше" → "exit" is the classic case no statistics can catch). Undo an auto-correction and it remembers to leave that word as typed. Settings → Learned words: view the list, remove entries, or reset it. Nothing is learned from password fields or excluded apps.
- With several layouts of the same script enabled (say Russian and Ukrainian), the hotkey now picks the target layout by how well the result reads, instead of by list order.
- Experimental, off by default: Settings → "Between similar layouts (uk ↔ ru)". Auto-correct then also fixes a Ukrainian word typed on the Russian layout and the other way round ("ъжа" → "їжа", "єкран" → "экран"), or just switches the layout when the letters happen to be the same ("мабуть"). It only acts on words the two languages clearly tell apart, so many common words stay as they are — use the hotkey for those, and it will learn them.
- The Ukrainian language model was rebuilt from a cleaner word list: the old one contained a quarter Russian, which made Russian words typed on the Ukrainian layout look fine to it.
- Settings: a language change now applies to the Exceptions sheet too, the version line is localized, "Also fix on Enter" is now "Fix on Enter", and the window opens without the zoom animation.
