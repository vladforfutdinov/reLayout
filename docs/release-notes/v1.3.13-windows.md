## What's new in v1.3.13 — Windows (preview)

- Russian on the Ukrainian layout, Ukrainian on the Russian one and English on another Latin layout are no longer converted when that language's own layout is not installed ("еще" → "tot", "but" → "иге").
- Junk is no longer converted into different junk, and three-letter words that are real both ways ("рук" / "her") are fixed only together with a neighbouring wrong-layout word.
- "Between similar layouts" is available only with two layouts of one script in different languages; its ⓘ explains why.
