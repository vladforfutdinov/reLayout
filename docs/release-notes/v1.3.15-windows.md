## What's new in v1.3.15 — Windows (preview)

- Auto-correct on/off hotkey: record one in Settings (none by default); a green dot on the tray icon shows when auto-correct is on.
- Modifier chords such as Ctrl+Shift can now be recorded as a hotkey (single or double tap).
- New experimental option "Check with the system dictionary" (off by default), using Windows spell checking: fewer wrong conversions, missed words caught ("учше" → "exit"), one typo in a wrong-layout word fixed ("ghbddtn" → "привет").
- Learns from your edits: erase a wrong correction and retype the word to keep it; erase and retype a kept word to have it fixed again; fix a missed word by hand and it is remembered.
- Abbreviations typed in capitals (IBM, МФЦ) are never auto-corrected.
- Pressing the hotkey again undoes the last conversion until you type or click something else — no more 1.5-second limit.
- Settings: captions aligned left, info icons centred, the Learned words list in clear columns.
