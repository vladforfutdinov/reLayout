## What's new in v1.3.15 — macOS

- Auto-correct on/off hotkey: record one in Settings (none by default); a dot on the menu-bar icon shows when auto-correct is on.
- New experimental option "Check with the system dictionary" (off by default): a real word is no longer converted into junk, a word the old rules missed is converted when the dictionary knows it ("учше" → "exit"), and one typo in a word typed in the wrong layout is fixed too ("ghbddtn" → "привет").
- Learns from your edits: erase a wrong correction and type the word again — it is left alone from now on; erase and retype a word it left alone — it is fixed again; fix a missed word by hand ("учше", then "exit") — it is remembered.
- Abbreviations typed in capitals (IBM, МФЦ) are never auto-corrected.
- Pressing the hotkey again undoes the last conversion until you type or click something else — no more 1.5-second limit.
- Fixed: after switching the layout with Globe, a delayed key could make a correction erase one character too many ("anthropic оум" → "anthropicооум").
- Fixed: while a hotkey field in Settings stayed selected, both hotkeys and auto-correct were paused.
- Settings: an option unavailable on this Mac shows unchecked; one disabled only because auto-correct is off keeps its state.
