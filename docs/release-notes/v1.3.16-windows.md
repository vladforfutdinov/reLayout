## What's new in v1.3.16 — Windows (preview)

- Per-app exceptions now cover the hotkey too: each program in Settings → Exceptions… has two boxes, Auto-correct and Hotkey; with both ticked reLayout reads no keys there at all.
- Figma is in the exceptions by default with both boxes ticked, so its single-key tool shortcuts are left alone.
- The Exceptions… button moved to its own section in Settings.
- Thanks to @lsl87Serhii, whose contribution (#1, #3) started this feature.
