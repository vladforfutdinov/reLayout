## What's new in v1.3.16 — macOS

- Per-app exceptions now cover the hotkey too: each program in Settings → Exceptions… has two boxes, Auto-correct and Hotkey; with both ticked reLayout reads no keys there at all.
- Figma is in the exceptions by default with both boxes ticked: releasing Option there no longer fires the hotkey and spawns frames on the canvas.
- Exceptions follow Spotlight: it used to inherit the app underneath it (no auto-correct in Spotlight opened over a terminal); now Spotlight is treated as its own app.
- The Exceptions… button moved to its own section in Settings.
- Thanks to @lsl87Serhii for the first outside contribution — the per-app hotkey exception and the Figma fix (#1, #3) — and for the Spotlight hint (#2).
