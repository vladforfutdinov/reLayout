## What's new in v1.3.4 — macOS

- Auto-correct no longer skips the word right after a correction. Typing `цштвщці ghjcnj ` now fixes both words — before, the second one was often left exactly as typed.
- A word typed in the right layout is no longer retyped as itself right after a correction (a brief flicker that changed nothing).
- Both came from the same cause: for a moment after reLayout switched the layout, it read keystrokes as the letters of the *previous* layout, so what it judged no longer matched what was on screen.
