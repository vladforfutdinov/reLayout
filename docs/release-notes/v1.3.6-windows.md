## What's new in v1.3.6 — Windows (preview)

- The hotkey now works in consoles (Command Prompt, PowerShell, Windows Terminal): with nothing selected it converts the word you just typed — `ghbdtn` becomes `привет`. Selected text in a console is still left alone, since reading it would mean pressing Ctrl+C, which stops the running command.
- If you turned auto-correct on in a console, Return there is now left alone instead of going back to fix the word before it.
