## What's new in v1.3.6 — macOS

- If you turned auto-correct on in a terminal (removed it from *Exceptions*), Return there is now left alone: reLayout no longer goes back to fix the last word after Return. In a terminal Return runs the command, so a quiet one like `ssh ghbdtn` could have received stray backspaces.
- Reminder: with nothing selected, the hotkey converts the word you just typed — and that works in terminals too.
