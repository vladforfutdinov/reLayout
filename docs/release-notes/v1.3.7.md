## What's new in v1.3.7 — macOS

- Automatic updates now actually install. With "Automatically download and install updates" on, a new version used to download and then wait for you to quit reLayout — which a menu-bar app practically never does. Now reLayout installs the update and relaunches itself right away.
- If you're on 1.3.6 or older, quit reLayout once from the menu (or install this version manually) — after that, updates arrive on their own.
