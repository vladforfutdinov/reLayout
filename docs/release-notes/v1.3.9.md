## What's new in v1.3.9 — macOS

- Auto-correct now fixes a run of short words typed in the wrong layout: "пщ ещ еру" becomes "go to the" as you type. Before, a 1–2 letter word was only corrected next to a longer one, so a chain of short words was left as is.
- A single short word followed by text you typed after switching the layout by hand ("пщ to the") is still left alone — select it and press the hotkey.
