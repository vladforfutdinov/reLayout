## What's new in v1.4.0 — Windows (preview)

- **New default hotkey: Left Shift twice** (Ctrl+Alt+R is AltGr on many European layouts). If you never changed the hotkey, you keep Ctrl+Alt+R; ↺ next to the hotkey in Settings switches to the new default. Shift held for a capital or for Shift+click never fires it.
- **Exceptions are now Apps…** Settings → "Allow features per app" → Apps… lists programs with two boxes, Auto-correct and Hotkey; a tick now means the feature works there. Your existing setup carries over unchanged.
- A newly added program (Add current app, +) starts with both off; on a fresh install terminals, code editors, VMs, remote desktops and Figma are listed that way.
- Apps… and View… (Learned words) are modal to Settings. In the dark theme their check boxes are dark and the lists have no column lines; in the light theme the row under the mouse is highlighted.
- Much smaller download: installer 18 → 5.5 MB, portable exe 16 → 3.5 MB.
- "Check with the system dictionary" now actually works while you type.
- Keyboard handling runs on its own thread: no more stalls that could drop keys or join words across a Tab.
- Remappers, on-screen keyboards and password-manager autotype no longer make a fix erase the wrong text.
- "Launch at login" now controls the installer's autostart; uninstalling removes everything, including your settings and learned words.
- Fixes: selections over 4095 characters are converted whole; Add current app names Store (UWP) apps correctly; pressing the hotkey again undoes with multi-tap hotkeys; a broken language file no longer crashes the app at start.
