## What's new in v1.4.0 — macOS

- **New default hotkey: tap Shift twice** (either Shift), the same as on Windows. If you never changed the hotkey, you keep the left ⌥ tap you know; ↺ next to the hotkey in Settings switches to the new default.
- **Exceptions are now Apps…** Settings → "Allow features per app" → Apps… lists programs with two boxes, Auto-correct and Hotkey; a tick now means the feature works there. Your existing setup carries over unchanged.
- A newly added app (Add current app, +) starts with both off; on a fresh install terminals, code editors, VMs, remote desktops and Figma are listed that way.
- Apps… and View… (Learned words) open as sheets on Settings; Done, Esc or ⌘W close them. Learned words has standard check boxes.
- Settings opens in front of the app you were in, not behind it.
- Pressing the hotkey again (undo, next layout) erases with Backspace instead of reselecting, so it works in terminals too — no more `;2D` junk with the original text appended.
- Keys you type while a word is being fixed come out in the new layout and in order.
- A word typed across a layout switch on punctuation keys (`[jh` + `ошо`) is fixed, and a double-clicked word with its trailing space is fixed as one word.
- Tab no longer joins words: a fix never reaches back across a Tab.
- Fixes: a hung app can no longer stall the keyboard; the copy fallback waits for the clipboard and works with Dvorak; the Enter fix works in fields with CRLF line ends; after a click the hotkey no longer "undoes" text it never converted.
- The updater (Sparkle) is updated to 2.10.0 with its security fixes.
