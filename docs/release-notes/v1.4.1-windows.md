## What's new in v1.4.1 — Windows

- **Exceptions…** In Settings, the per-app row is now a single Exceptions… button. Its window opens with the hint that explains the two boxes.
- Settings dialogs (Exceptions, Learned words) have no title bar, and on Windows 11 they have rounded corners.
- **The portable exe starts again.** Since at least v1.3.16 it unpacked itself, showed nothing and hung; the installer was not affected.
- License notices for the auto-correct models and the bundled Swift runtime now ship next to the exe.
