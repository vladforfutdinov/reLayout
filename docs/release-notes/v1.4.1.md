## What's new in v1.4.1 — macOS

- **Fn works in hotkeys.** You can record a chord with Fn (shown as `fn + ⌥`) or tap Fn alone.
- **Apps… is now Exceptions…** In Settings, the "Allow features per app" row is replaced by a single Exceptions… button. The hint that used to sit in its ⓘ tooltip now opens at the top of the sheet.
- **Credits.** A new Credits button under the copyright in Settings shows the licenses of what ships with the app: the updater (Sparkle) and the auto-correct language models.
- Settings buttons now use the same text size as the rest of the window, and all three sheets (Exceptions, Learned words, Credits) have the same footer with Done on the right.
