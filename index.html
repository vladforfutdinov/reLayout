Wrong keyboard layout?
Fixed in one keystroke.

reLayout retypes text you typed in the wrong layout and flips the input source. Punto-style, for macOS and Windows.

What it does

Small app, exactly the right behavior.

It converts over your actually-installed layouts using physical key positions, so it is never hard-coded to a single pair.

Any layouts, by key position

Not a character table. It maps through physical keys, so even the Option layer just works.

ß æ  →  ы э

Auto-correct as you type

A per-language trigram model fixes wrong-layout words on the fly, no hotkey. Cross-script, precision-first, learns from your undos. Off by default.

Your hotkey

Shift tapped twice by default. Or record a combo, a modifier tap or a tap sequence of your own.

Press again

Hit it again for the next layout's reading; once there is none left, the original text and input source come back.

Reads quietly

Accessibility on macOS, UI Automation on Windows. The clipboard only when an app shows no text, and it is put back. DeepL stays out of the way.

Per-app features

Choose per app whether auto-correct and the hotkey work. Terminals, IDEs and virtual machines start with both off; password fields are always skipped.

Stays current on its own

On macOS: signed, notarized, auto-updating via Sparkle, or through Homebrew. On Windows: a tray notice when a new release is out.

Built for the messy reality

Real typing is messy. reLayout covers the cases the simple switchers skip.

Just typed it?

Nothing selected? The hotkey converts the word you have just typed. It never guesses at text it did not see you type.

Switched layout after mistyping?

It reads the wrong layout from the text itself, not just the active one.

Option-layer characters?

Even ß and æ map to ы and э. It works on key position, not a letter table.

Any script you use?

Ukrainian, English, anything installed. With three or more layouts, pressing again tries the next one.

In a password field?

Secure text fields are always left alone, hotkey and auto-correct both.

In a terminal, an IDE or a VM?

Both features start off there — a VM's guest has its own layout. Tick what should work in Apps….

Changed your mind?

Press the hotkey again before you type or click anything: the next reading, then the original text back.

Want a different hotkey?

Shift twice is the default. Record a combo, a modifier tap or another tap sequence instead.

Everything the popular layout switchers do, plus what they usually don't: any installed layout, a clipboard-free read, and open source.

Launch reLayout. It lives in the menu bar as the icon.
